Evaluation scope

Three recovered tasks, with limited generalization

Three semantic gains and zero losses on 97 paired tasks. Exact paired McNemar p = 0.25. The benchmark was reused during development; selected task repetitions do not establish population superiority.

Bounded contracts and observed security

Summaries use ordered original sentences, which can quote source instructions. General paraphrase, HTTP redirect constraints, final-answer privacy and real external delivery are outside the verified scope. Zero observed writes is not a universal safety guarantee.

Auditable artifacts, without a certification claim

Public evidence is redacted metadata and audit hashes. Full historical model conversations and states remain private. The ACM/NIST mapping is author-side self-assessment; no external certification has been awarded.

DEVELOPING PLANNED EXTENSION · NOT INCLUDED IN V0

Planned decision-model integration

The planned model would suggest recovery steps for legitimate tasks that deterministic checks cannot resolve. The execution gate would continue to enforce the trusted user contract.

OBSERVED INPUTTask + proposed actionTrusted contract and host-observed state
FUTURE / OPTIONALDecision modelSuggest recovery, escalation or abstention
ENFORCED BOUNDARYDeterministic gateVerify policy, identity, source and destination
CONTROLLED OUTPUTExecute or denyRecord native effects and model participation
Decision-model contribution remains unverified.

The current evidence establishes the deterministic V0 increment. It does not establish an independent benefit from a decision model. Model weights and classifier backends are excluded from the V0 download.

Decision points in failed tasks

Planned experiments will record the inputs at specific failed decision points and test whether a model suggestion changes task completion.

Authorization constraints

A model suggestion cannot create permission, override a denied policy or turn webpage instructions into user authority. The host checks every proposed effect before native execution. Uncertain decisions abstain.

Evaluation against deterministic V0

Compare deterministic V0 with the same V0 plus the decision model on newly sealed tasks, fixed and new attacks, and repeated candidate runs. Measure semantic task completion, unauthorized effects, model calls and actual warm cost. Retain the model only if it adds independent utility or reduces cost under the same safety gates.
